# Тестовые сценарии

Запуск: `php -S localhost:8000 -t public`, затем открыть `http://localhost:8000`.

| № | Сценарий | Действие | Ожидаемый результат |
|---|---|---|---|
| 1 | Каталог | Открыть главную страницу без параметров | Показаны 30 книг и счётчик результатов |
| 2 | Поиск по названию | Ввести `Булгаков` | Найдена книга «Мастер и Маргарита» |
| 3 | Поиск без учёта регистра | Ввести `дЮнА` | Найдена книга «Дюна» |
| 4 | Фильтр по жанру | Выбрать `Фантастика` | Показаны книги выбранного жанра |
| 5 | Фильтр по году | Выбрать `1984` | Показана книга «1984» издания 1949 года? Нет: фильтр ищет год издания, поэтому при выборе 1984 результат пустой |
| 6 | Сортировка | Выбрать «Сначала новые» | Сначала отображаются книги с более поздним годом |
| 7 | Пустой результат | Ввести случайный запрос, например `zz_no_book_999` | Появляется сообщение «Ничего не найдено» и кнопка сброса |
| 8 | Карточка книги | Нажать «Подробнее» | Открывается карточка с описанием и годом |
| 9 | Добавление в избранное | Нажать ♡ на книге | Книга добавляется; отображается flash-сообщение |
| 10 | Сохранение избранного | Перейти в каталог и обратно в избранное в той же сессии | Книга остаётся в списке |
| 11 | Удаление из избранного | Нажать ♥ на карточке | Книга удаляется из списка |
| 12 | CSRF | Отправить POST без токена | Запрос отклонён с HTTP 403 |
| 13 | Неподдерживаемый метод | Открыть `favorite.php` напрямую через GET | Ответ HTTP 405 |
| 14 | Несуществующий ID | Открыть `book.php?id=99999` | Ответ HTTP 404 и сообщение «Книга не найдена» |
| 15 | XSS-проверка | Ввести `<script>alert(1)</script>` в поиск | Строка рассматривается как текст поиска и не исполняется |

## Примечание к сценарию 5

В каталоге есть книга с названием «1984», но её год издания указан как 1949. Поэтому фильтр по году `1984` корректно не находит её. Для демонстрации фильтра по году используйте 1949.

## Граничные проверки

- Пустая строка поиска возвращает весь каталог.
- Неизвестный параметр сортировки заменяется сортировкой по названию.
- Неположительный или нечисловой ID не должен открыть чужую запись.
- Неверный CSRF-токен не изменяет список избранного.
