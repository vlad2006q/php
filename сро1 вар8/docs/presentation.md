# План презентации (9 слайдов, 5–7 минут)

1. **Титульный слайд.** Электронный каталог библиотеки, вариант 8, ФИО, группа, ссылка на GitHub.
2. **Проблема и цель.** Упростить поиск книг и формирование личного списка избранного.
3. **Требования.** Поиск, фильтры по жанру/году, сортировка, карточка книги, избранное.
4. **Технологии.** PHP 8.4, HTML5, CSS, JSON, PHP Sessions, GitHub.
5. **Архитектура.** Браузер → `public/index.php` → функции в `src/functions.php` → `var/data/books.json`; избранное хранится в сессии.
6. **Демонстрация каталога.** Скриншот главной страницы и поиск по автору.
7. **Безопасность.** `htmlspecialchars()`, серверная проверка ID, POST, CSRF-токен, настройки сессионной cookie.
8. **Тестирование.** Обычный сценарий, пустой результат, несуществующий ID, неверный CSRF-токен.
9. **Итоги и развитие.** Что реализовано, ограничения, идеи развития; ссылка на GitHub.

Перед выступлением замените поля ФИО и группы, добавьте ссылку на собственный репозиторий и скриншоты работающего приложения. Не показывайте скриншоты, которые не соответствуют текущей версии кода.
