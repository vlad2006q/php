# Электронный каталог библиотеки

**Вариант 8 · Дисциплина «Программирование на PHP» · PHP 8.4+**

Учебное веб-приложение для поиска книг, фильтрации по жанру и году, сортировки и хранения избранных книг в PHP-сессии. Данные каталога хранятся в JSON без СУБД.

## Возможности

- Каталог из 30 демонстрационных книг.
- Поиск по названию, автору и описанию без учёта регистра.
- Фильтрация по жанру и году издания.
- Сортировка по названию и году.
- Отдельная страница книги и страница избранного.
- Избранное хранится в `$_SESSION`; cookie сессии настроена с `HttpOnly` и `SameSite=Lax`.
- Все изменяющие действия выполняются методом POST и проверяют CSRF-токен.
- Весь пользовательский и динамический текст экранируется через `htmlspecialchars()`.
- Типизация и `declare(strict_types=1)` в PHP-файлах.

## Требования

- PHP 8.4 или новее.
- Расширения PHP `json` и `session`. Если доступно `mbstring`, оно используется для Unicode-поиска; в противном случае включён резервный вариант для кириллицы.
- База данных и сторонние PHP-библиотеки не нужны.

Проверить версию PHP:

```bash
php -v
```

## Запуск в VS Code на Windows

1. Скачайте или клонируйте репозиторий и откройте папку проекта в VS Code.
2. Убедитесь, что команда `php -v` работает в терминале VS Code. Если команда не найдена, установите PHP 8.4+ и добавьте папку PHP в `PATH`.
3. Из корневой папки проекта выполните:

```powershell
php -S localhost:8000 -t public
```

4. Откройте в браузере `http://localhost:8000`.
5. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

На Linux/macOS команда запуска такая же. Для локальной демонстрации встроенный сервер PHP подходит; для реального публичного размещения следует использовать настроенный веб-сервер и HTTPS.

## Архитектура и безопасность

Браузер отправляет GET-параметры для поиска и фильтров. `public/index.php` передаёт их функции `filterBooks()`, которая работает с данными из JSON. Избранное изменяется только через POST-запрос к `favorite.php`; токен сверяется через `hash_equals()`. ID книги проверяется по существующему каталогу. При выводе данных используется `htmlspecialchars()`.

## Ограничения

Это учебный каталог без административного интерфейса, базы данных и реальной системы выдачи книг. Избранное связано с сессией текущего браузера и не синхронизируется между устройствами.
